# Week 1 Assignment

This repository contains the Week 1 assignment for the DevOps-GTP program.

## Repository Structure

- **assigment.py**: A Python script for the Week 1 assignment.
- **Adjei_Mensah/**: Contains supporting files, including:
  - `Adjei_Mensah.txt`: A text file with generated by running the assigment.
  - `Screenshot 2025-04-14 at 9.13.37 AM.png`: A screenshot for the assignment.
- **venv/**: A Python virtual environment for managing dependencies.

## How to Use

1. Clone the repository:
   ```bash
   git clone <https://github.com/Adjei-GTP-DevOps/Assignment-Week-1>
   ```

2. Activate the virtual environment:
   ```bash
   source venv/bin/activate
   ```

3. Run the Python script:
   ```bash
   python assigment.py
   ```

## Notes

- Ensure you have Python installed on your system.
- Activate the virtual environment before running the script to ensure all dependencies are available.
